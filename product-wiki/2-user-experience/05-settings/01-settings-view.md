# 2.2.9. 설정 (Settings)

## 주요 개념 정의

- **워크스페이스 (Workspace):** 모든 작업(캠페인, 사용자, 템플릿 등)이 이루어지는 최상위 그룹 단위입니다. 팀 또는 프로젝트별로 워크스페이스를 분리하여 사용할 수 있습니다.
- **연동 (Integration):** 파이핸즈 CRM을 Slack, Mixpanel 등 외부 서비스와 연결하여 기능을 확장하는 것을 의미합니다.

- **위치:** GNB > `설정`
- **역할:** 워크스페이스의 기본 정보, 사용자 초대 및 관리, 외부 서비스 연동 등 시스템의 전반적인 환경을 설정하는 페이지.

---

### 기능: 워크스페이스 정보 관리

> **목표:** 사용자는 자신이 속한 워크스페이스의 이름을 변경할 수 있다.

**시나리오 1: 워크스페이스 이름 변경**

`Given` 사용자가 '설정' 페이지의 '워크스페이스' 탭에 있다
`And` 현재 워크스페이스의 이름은 "My First Workspace" 이다
`When` 사용자가 `워크스페이스 이름` 입력 필드의 내용을 "Piehands Marketing Team" 으로 변경한다
`And` `저장` 버튼을 클릭한다
`Then` "워크스페이스 정보가 저장되었습니다." 라는 성공 토스트 메시지가 나타나야 한다
`And` GNB 상단 또는 페이지 헤더에 표시된 워크스페이스 이름이 "Piehands Marketing Team"으로 변경되어야 한다

---

### 기능: 외부 서비스 연동

> **목표:** 사용자는 외부 서비스를 연동하여 CRM의 기능을 확장할 수 있다.

**시나리오 2: Slack 연동 설정**

`Given` 사용자가 '설정' 페이지의 '연동' 탭에 있다
`And` Slack 연동 섹션에는 `Webhook URL` 입력 필드가 있다
`When` 사용자가 유효한 Slack Webhook URL을 입력 필드에 붙여넣는다
`And` `연결 테스트` 버튼을 클릭한다
`Then` 시스템은 해당 URL로 테스트 메시지를 발송해야 한다
`And` 잠시 후 "Slack 연동 테스트 성공!" 이라는 메시지가 표시되어야 한다
`And` 사용자가 `저장` 버튼을 클릭한다
`Then` Slack 연동 상태가 '연결됨'으로 표시되어야 한다

**시나리오 3: Mixpanel 연동 설정**

`Given` 사용자가 '설정' 페이지의 '연동' 탭에 있다
`And` Mixpanel 연동 섹션에는 `Project Token` 입력 필드가 있다
`When` 사용자가 유효한 Mixpanel Project Token을 입력하고 `저장` 버튼을 클릭한다
`Then` "Mixpanel 연동 정보가 저장되었습니다." 라는 성공 토스트 메시지가 나타나야 한다
`And` Mixpanel 연동 상태가 '연결됨'으로 표시되어야 한다

---

### 기능: 팀원 관리 (미래 기능)

> **목표:** 관리자는 워크스페이스에 새로운 팀원을 초대하거나 기존 팀원의 역할을 변경할 수 있다.

**시나리오 4: 새 팀원 초대**

`Given` 사용자가 '설정' 페이지의 '팀원' 탭에 있다
`When` 사용자가 `+ 팀원 초대` 버튼을 클릭한다
`Then` 초대할 사람의 이메일 주소와 역할을 선택하는 모달 창이 나타나야 한다
