# 2.6.2. 실시간 AI 문구 생성 템플릿

- **위치:** 템플릿 편집기 (`/03-templates/02-template-editor.md`)
- **역할:** 팀 멤버가 이메일/SMS 템플릿 내부에 특수한 `{{llm.generate()}}` 변수를 사용하여, 메시지 발송 시점에 LLM(AI)이 각 유저를 위해 개인화된 문구를 실시간으로 생성하도록 하는 기능.

---

### 기능: AI 생성 변수 사용

> **목표:** 팀 멤버는 템플릿 편집기에서 AI가 생성할 문구의 프롬프트를 정의하고, 타임아웃 및 실패 시의 대체 문구를 설정할 수 있다.

**시나리오 1: 템플릿에 AI 생성 변수 삽입**

`Given` 팀 멤버가 '템플릿 편집기'에서 이메일 본문을 작성 중이다
`When` 팀 멤버가 `+ 변수 삽입` 버튼 메뉴에서 `AI 문구 생성`을 선택한다
`Then` "AI 문구 생성" 설정 모달이 나타나야 한다
`And` 모달에는 `프롬프트`, `최대 토큰 수`, `타임아웃(초)`, `실패 시 대체 문구` 입력 필드가 있어야 한다

`Given` 팀 멤버가 "AI 문구 생성" 모달을 보고 있다
`When` 팀 멤버가 `프롬프트`에 "오늘 {{user.last_purchased_item}} 상품을 구매한 {{user.level}} 등급 고객에게 보낼 짧은 감사 메시지" 라고 입력한다
`And` `실패 시 대체 문구`에 "구매해주셔서 감사합니다!" 라고 입력한다
`And` `삽입` 버튼을 클릭한다
`Then` 편집기 본문에 `{{llm.generate(prompt: "...", fallback: "...")}}` 와 같은 형태의 특수 변수가 삽입되어야 한다

---

### 기능: AI 문구 생성 비동기 처리

> **목표:** LLM 호출이 오래 걸리더라도, 다른 일반 메시지 발송이 지연되어서는 안 된다.

**시나리오 2: AI 변수가 포함된 이메일 발송 요청**

`Given` 유저 "user-789"가 `{{llm.generate(...)}}` 변수가 포함된 템플릿을 사용하는 캠페인에 참여했다
`When` 유저가 캔버스의 `이메일 발송` 노드에 도달한다
`Then` 시스템은 해당 발송 작업을 즉시 **'LLM 처리 전용 큐'**로 보내야 한다
`And` 메인 발송 워커는 지연 없이 다음 유저의 작업을 처리해야 한다

**시나리오 3: LLM 호출 성공 및 최종 발송**

`Given` 'LLM 처리 전용 큐'에 "user-789"를 위한 작업이 있다
`When` 'LLM 전용 워커'가 해당 작업을 처리하고, LLM API를 호출하여 "멋진 {{user.last_purchased_item}}을 구매해주셔서 감사합니다, VIP 고객님!" 이라는 문구를 성공적으로 생성한다
`Then` 생성된 문구가 포함된 최종 이메일이 "user-789"에게 발송되어야 한다

**시나리오 4: LLM 호출 실패 또는 타임아웃**

`Given` 'LLM 처리 전용 큐'에 "user-789"를 위한 작업이 있다
`When` 'LLM 전용 워커'가 LLM API를 호출했지만, 설정된 타임아웃(15초)을 초과하거나 에러가 발생한다
`Then` 템플릿에 미리 정의된 **`실패 시 대체 문구`**("구매해주셔서 감사합니다!")가 포함된 이메일이 "user-789"에게 발송되어야 한다

---
### 정책 정의
- **프롬프트 최대 길이:** 1,000자
- **최대 토큰 수 기본값:** 150
- **타임아웃 기본값:** 15초
