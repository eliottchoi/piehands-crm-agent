# 2.2.5. 템플릿 목록 (Template List)

## 주요 개념 정의

- **템플릿 (Template):** 캔버스의 `이메일 발송`과 같은 액션 노드에서 사용하는 재사용 가능한 콘텐츠 조각입니다. `{{user.name}}`과 같이 유저의 속성을 가져와 개인화된 메시지를 만드는 변수를 포함할 수 있습니다.
- **템플릿 유형 (Type):** 템플릿이 사용될 채널을 의미합니다. (예: `Email`, `SMS`)

- **위치:** GNB > `템플릿`
- **역할:** 생성된 모든 유형의 템플릿을 관리하는 라이브러리. 템플릿 생성, 검색, 복제, 삭제 등의 작업을 수행한다.

---

### 기능: 템플릿 목록 조회 및 검색

> **목표:** 팀 멤버는 자신이 생성한 템플릿을 쉽게 찾고 관리할 수 있다.

**시나리오 1: 기본 목록 조회**

`Given` 팀 멤버가 '템플릿 목록' 페이지에 있다
`Then` 생성된 모든 템플릿이 카드 또는 목록 형태로 표시되어야 한다
`And` 각 항목에는 `템플릿 이름`, `템플릿 유형`, `최근 수정일` 정보가 표시되어야 한다

**시나리오 2: 템플릿 검색**

`Given` 팀 멤버가 '템플릿 목록' 페이지에 있다
`When` 팀 멤버가 페이지 상단의 검색창에 "환영"이라고 입력한다
`Then` 템플릿 이름에 "환영"이 포함된 템플릿만 표시되어야 한다

---

### 기능: 새 템플릿 생성

> **목표:** 팀 멤버는 새로운 템플릿 생성을 시작할 수 있다.

**시나리오 3: 새 이메일 템플릿 생성 시작**

`Given` 팀 멤버가 '템플릿 목록' 페이지에 있다
`When` 팀 멤버가 `+ 새 템플릿 만들기` 버튼을 클릭한다
`Then` "어떤 유형의 템플릿을 만드시겠습니까?" 라는 옵션(`Email`, `SMS` 등)이 포함된 선택지가 나타나야 한다
`And` 팀 멤버가 `Email` 유형을 선택한다
`Then` '템플릿 편집기' 페이지로 이동해야 한다
`And` 페이지 상단에는 "새 이메일 템플릿"이라는 제목이 표시되어야 한다
`And` (상세 흐름은 '템플릿 편집기' 문서에서 계속)

---

### 기능: 템플릿 관리

> **목표:** 팀 멤버는 기존 템플릿을 복제하거나 삭제하여 효율적으로 관리할 수 있다.

**시나리오 4: 템플릿 복제**

`Given` "신규 가입자 환영" 이메일 템플릿이 목록에 존재한다
`When` 팀 멤버가 해당 템플릿의 컨텍스트 메뉴(`...`)에서 `복제` 옵션을 클릭한다
`Then` "신규 가입자 환영 (복사본)" 이라는 이름의 새로운 템플릿이 생성되어야 한다
`And` 복제된 템플릿은 원본과 동일한 내용과 설정을 가져야 한다
`And` 팀 멤버는 복제된 템플릿의 '템플릿 편집기' 페이지로 즉시 이동해야 한다
