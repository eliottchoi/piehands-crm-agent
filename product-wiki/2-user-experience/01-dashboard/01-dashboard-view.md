# 2.2.2. 대시보드 (Dashboard)

## 주요 개념 정의

- **핵심 지표 (Key Metrics):** 현재 시스템의 전반적인 상태와 성과를 요약하여 보여주는 주요 데이터입니다. (예: 활성 캠페인 수, 총 발송 메시지 수)
- **활동 피드 (Activity Feed):** 시스템 내에서 발생하는 주요 이벤트들을 시간순으로 보여주는 실시간 로그입니다.

- **위치:** GNB > `대시보드` (로그인 후 기본 랜딩 페이지)
- **역할:** 팀 멤버가 시스템의 현황을 한눈에 파악하고, 다음에 수행해야 할 중요한 작업을 인지할 수 있도록 돕는 정보 허브.

---

### 기능: 핵심 지표 확인

> **목표:** 팀 멤버는 대시보드를 통해 현재 운영 중인 캠페인의 전반적인 성과와 시스템 상태를 빠르게 파악할 수 있다.

**시나리오 1: 대시보드 진입 시 핵심 지표 확인**

`Given` 팀 멤버가 시스템에 로그인했다
`Then` 팀 멤버는 '대시보드' 페이지로 이동해야 한다
`And` 페이지 상단에는 "핵심 지표" 섹션이 보여야 한다
`And` "핵심 지표" 섹션에는 `활성 캠페인 수`, `현재 여정 진행 중인 총 유저 수`, `오늘 발송된 총 메시지 수`가 각각의 카드 형태로 표시되어야 한다

---

### 기능: 실시간 활동 피드 확인

> **목표:** 팀 멤버는 대시보드에서 현재 시스템을 통해 상호작용하고 있는 유저와 캠페인의 활동을 실시간으로 확인할 수 있다.

**시나리오 2: 유저 활동 피드 조회**

`Given` "홍길동" 유저가 방금 "신규 가입자 환영" 캠페인에 참여했다
`When` 팀 멤버가 '대시보드' 페이지를 본다
`Then` 페이지에는 "유저 활동 피드" 섹션이 보여야 한다
`And` "유저 활동 피드" 최상단에는 "홍길동님이 '신규 가입자 환영' 캠페인에 참여했습니다." 라는 항목이 보여야 한다
`And` 피드 항목을 클릭하면 해당 유저의 상세 페이지로 이동해야 한다

**시나리오 3: 캠페인 활동 피드 조회**

`Given` "4분기 프로모션" 캠페인이 방금 `ACTIVE` 상태로 변경되었다
`When` 팀 멤버가 '대시보드' 페이지를 본다
`Then` 페이지에는 "캠페인 활동 피드" 섹션이 보여야 한다
`And` "캠페인 활동 피드" 최상단에는 "'4분기 프로모션' 캠페인이 활성화되었습니다." 라는 항목이 보여야 한다
`And` 피드 항목을 클릭하면 해당 캠페인의 성과 분석 페이지로 이동해야 한다
