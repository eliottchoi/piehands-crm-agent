# 2.2.3. 캠페인 목록 (Campaign List)

## 주요 개념 정의

- **캠페인 (Campaign):** 모든 마케팅 활동을 위한 최상위 조직 단위입니다. 하나의 캠페인은 하나의 명확한 마케팅 목표를 나타내며, 그 실행 로직으로 단 하나의 캔버스(Canvas)를 가집니다.
- **캠페인 상태 (Status):**
  - `DRAFT`: 생성 중인 상태. 아직 활성화되지 않아 유저가 진입할 수 없습니다.
  - `ACTIVE`: 라이브 상태. 유저가 진입하여 여정을 시작할 수 있습니다.
  - `INACTIVE`: 일시 중지된 상태. 신규 유저는 진입할 수 없습니다.
  - `ARCHIVED`: 종료되어 목록에서 보관 처리된 상태.

- **위치:** GNB > `캠페인`
- **역할:** 팀 멤버가 생성한 모든 캠페인을 관리하는 메인 허브. 캠페인 생성, 조회, 상태 변경, 성과 요약 확인 등 모든 캠페인 관리 작업의 시작점 역할을 한다.

---

### 기능: 캠페인 목록 조회

> **목표:** 팀 멤버는 자신이 생성한 캠페인 목록을 명확하게 인지하고, 원하는 캠페인을 쉽게 찾을 수 있다.

**시나리오 1: 기본 목록 조회**

`Given` 팀 멤버가 시스템에 로그인해 있다
`When` 팀 멤버가 GNB(메인 메뉴)에서 `캠페인` 링크를 클릭한다
`Then` '캠페인 목록' 페이지로 이동해야 한다
`And` 페이지에는 `DRAFT`, `ACTIVE`, `INACTIVE` 상태의 모든 캠페인이 테이블 형태로 표시되어야 한다
`And` 각 행(Row)에는 `캠페인 이름`, `상태`(뱃지), `참여자 수`, `최근 수정일` 컬럼이 기본적으로 보여야 한다

**시나리오 2: 보관된 캠페인 필터링**

`Given` 팀 멤버가 '캠페인 목록' 페이지에 있다
`And` 목록 상단에는 `상태` 필터 드롭다운이 '활성 캠페인'으로 기본 설정되어 있다
`When` 팀 멤버가 `상태` 필터를 '보관된 캠페인'으로 변경한다
`Then` 테이블에는 `ARCHIVED` 상태의 캠페인만 표시되어야 한다

---

### 기능: 캠페인 생성

> **목표:** 팀 멤버는 캠페인 목록 페이지에서 새로운 캠페인 생성을 시작할 수 있다.

**시나리오 3: 새 캠페인 생성 시작**

`Given` 팀 멤버가 '캠페인 목록' 페이지에 있다
`When` 팀 멤버가 페이지 우측 상단의 `+ 새 캠페인 만들기` 버튼을 클릭한다
`Then` '새 캠페인 만들기' 모달(Modal) 창이 나타나야 한다
`And` (상세 흐름은 '캠페인 생성 및 캔버스 편집' 문서에서 계속)

---

### 기능: 캠페인 관리 (상태 변경 및 삭제)

> **목표:** 팀 멤버는 캠페인 목록 페이지에서 각 캠페인의 상태를 직접 변경하거나 안전하게 삭제할 수 있다.

**시나리오 4: 캠페인 활성화**

`Given` "신규 가입자 환영" 캠페인이 `DRAFT` 상태로 목록에 존재한다
`When` 팀 멤버가 해당 캠페인의 컨텍스트 메뉴(`...`)에서 `활성화` 옵션을 클릭한다
`Then` "캠페인을 활성화하면 유저들이 즉시 여정을 시작할 수 있습니다. 계속하시겠습니까?" 라는 내용의 확인 모달이 나타나야 한다

`Given` 팀 멤버가 활성화 확인 모달을 보고 있다
`When` 팀 멤버가 `확인` 버튼을 클릭한다
`Then` 해당 캠페인의 `상태`가 `ACTIVE` 뱃지로 변경되어야 한다
`And` 팀 멤버에게 "캠페인이 활성화되었습니다." 라는 성공 토스트 메시지가 나타나야 한다

**시나리오 5: 활성화된 캠페인은 수정 및 삭제 불가**

`Given` "신규 가입자 환영" 캠페인이 `ACTIVE` 상태로 목록에 존재한다
`When` 팀 멤버가 해당 캠페인의 컨텍스트 메뉴(`...`)를 클릭한다
`Then` 메뉴의 `이름/설명 변경` 옵션과 `삭제` 옵션은 비활성화(disabled) 상태로 보여야 한다

**시나리오 6: 한 번이라도 활성화되었던 캠페인 삭제 시 경고**

`Given` "4분기 프로모션" 캠페인이 `INACTIVE` 상태이다
`And` 이 캠페인은 과거에 `ACTIVE` 상태였던 이력이 있다
`When` 팀 멤버가 해당 캠페인의 컨텍스트 메뉴에서 `삭제`를 클릭한다
`Then` "이 캠페인은 과거에 활성화된 이력이 있습니다. 삭제하면 관련 성과 데이터 조회가 불가능해집니다. 정말 삭제하시겠습니까?" 라는 강력한 경고가 포함된 확인 모달이 나타나야 한다
`And` 확인 모달에는 "위험을 인지했으며, 영구적으로 삭제합니다." 라는 문구를 직접 입력해야만 `삭제 확인` 버튼이 활성화되는 안전장치가 있어야 한다

**시나리오 7: 활성화된 적 없는 초안 캠페인 삭제**

`Given` "미완성 아이디어" 캠페인이 `DRAFT` 상태이다
`And` 이 캠페인은 한 번도 `ACTIVE` 상태였던 적이 없다
`When` 팀 멤버가 해당 캠페인의 컨텍스트 메뉴에서 `삭제`를 클릭한다
`Then` "캠페인을 정말 삭제하시겠습니까?" 라는 일반적인 확인 모달이 나타나야 한다
