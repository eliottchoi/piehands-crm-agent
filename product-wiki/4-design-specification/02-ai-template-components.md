# 4.2. AI 템플릿 기능 컴포넌트

이 문서는 '실시간 AI 문구 생성' 기능과 관련된 UI 컴포넌트의 디자인 명세를 정의합니다.

---

### 1. 템플릿 편집기: `+ 변수 삽입` 버튼

템플릿 편집기 툴바에 위치하는 버튼으로, 동적 변수를 삽입하는 메뉴를 엽니다.

- **컴포넌트:** 드롭다운 메뉴를 포함한 버튼
- **버튼 레이블:** `+ 변수 삽입`
- **스타일:** `Secondary Button` 스타일 적용 ([스타일 가이드](./01-style-guide.md) 참조)
- **메뉴 항목:**
    - 사용자 속성 (예: `{{user.name}}`, `{{user.email}}`)
    - ... (기타 변수)
    - --- (구분선) ---
    - **`AI 문구 생성...`**

---

### 2. `AI 문구 생성` 설정 모달

`+ 변수 삽입` 메뉴에서 `AI 문구 생성...`을 클릭했을 때 나타나는 모달 창입니다.

- **모달 제목:** `AI 문구 생성`
- **레이아웃 스케치:**
    ```
    +-----------------------------------------+
    | AI 문구 생성                      [ X ] |
    +-----------------------------------------+
    |                                         |
    |  프롬프트                               |
    | +-------------------------------------+ |
    | | 오늘 {{user.last_...}}에게 보낼... | |
    | |                                     | |
    | +-------------------------------------+ |
    |  * 변수를 사용하여 개인화된 프롬프트...  |
    |                                         |
    | +------------------+ +----------------+ |
    | | 최대 토큰 수     | | 타임아웃 (초)  | |
    | | [ 150        ] | | [ 15         ] | |
    | +------------------+ +----------------+ |
    |                                         |
    |  실패 시 대체 문구                      |
    | +-------------------------------------+ |
    | | [ 구매해주셔서 감사합니다!      ] | |
    | +-------------------------------------+ |
    |                                         |
    |                      +--------+ +-----+ |
    |                      | 취소   | | 삽입| |
    |                      +--------+ +-----+ |
    +-----------------------------------------+
    ```
- **레이아웃:**
    - **프롬프트 (Prompt):**
        - **레이블:** `프롬프트`
        - **컴포넌트:** `Textarea` (높이 조절 가능, 최소 3줄)
        - **Placeholder:** `예: 오늘 {{user.last_purchased_item}} 상품을 구매한 {{user.level}} 등급 고객에게 보낼 짧은 감사 메시지`
        - **가이드 텍스트:** `사용자 속성 변수(예: {{user.name}})를 사용하여 개인화된 프롬프트를 만들 수 있습니다.`
    - **최대 토큰 수 (Max Tokens):**
        - **레이블:** `최대 토큰 수`
        - **컴포넌트:** `Input` (type="number")
        - **기본값:** `150`
    - **타임아웃 (Timeout):**
        - **레이블:** `타임아웃 (초)`
        - **컴포넌트:** `Input` (type="number")
        - **기본값:** `15`
    - **대체 문구 (Fallback Text):**
        - **레이블:** `실패 시 대체 문구`
        - **컴포넌트:** `Input` (type="text")
        - **Placeholder:** `예: 구매해주셔서 감사합니다!`
- **모달 버튼:**
    - `취소` (`Secondary Button`)
    - `변수 삽입` (`Primary Button`)

---

### 3. 편집기 내 `{{llm.generate()}}` 변수 표현

템플릿 편집기 본문에 AI 생성 변수가 삽입되었을 때, 다른 일반 텍스트나 변수와 시각적으로 구분되어야 합니다.

- **형태:** 태그(Tag) 또는 뱃지(Badge) 형태
- **배경색:** `Secondary` (`#F5A623`) 색상의 밝은 톤 (예: `#FEF5E7`)
- **글자색:** `Secondary` (`#F5A623`)
- **테두리:** `1px solid #F5A623`
- **텍스트:** `{{llm.generate(...)}}`
- **상호작용:** 클릭 시 `AI 문구 생성` 모달이 다시 열리며, 기존 설정값을 수정할 수 있어야 합니다.
