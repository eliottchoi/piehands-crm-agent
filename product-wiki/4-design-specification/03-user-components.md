# 4.3. 사용자 상세 페이지 컴포넌트

이 문서는 '사용자 상세' 페이지 내 이메일 상태 표시와 관련된 UI 컴포넌트의 디자인 명세를 정의합니다.

---

### 1. `email_status` 표시

사용자 상세 페이지의 프로필 헤더 영역에서 이메일 주소 옆에 현재 이메일 상태를 시각적으로 명확하게 표시합니다.

- **컴포넌트:** 뱃지 (Badge)
- **레이아웃 스케치:**
    ```
    +-------------------------------------------------------------+
    |                                                             |
    |  (👤)   홍길동                                              |
    |         hong.gildong@example.com [ active ✔️ ] [ 변경 ]      |
    |                                                             |
    +-------------------------------------------------------------+
    ```
- **위치:** 이메일 주소 바로 우측
- **스타일:**
    - `font-size`: `12px`
    - `font-weight`: `Medium`
    - `padding`: `4px 8px`
    - `border-radius`: `12px` (Pill shape)
    - `text-transform`: `capitalize` (첫 글자 대문자)

- **상태별 색상:**

| `email_status` | 배경색 | 글자색 | 아이콘 (선택 사항) |
| --- | --- | --- | --- |
| **`active`** | `Success` (`#7ED321`)의 밝은 톤 (예: `#E8F5E9`) | `Success` (`#7ED321`) | `✔️` (Check) |
| **`unsubscribed`** | `Secondary` (`#F5A623`)의 밝은 톤 (예: `#FEF5E7`) | `Secondary` (`#F5A623`) | `🚫` (Prohibited) |
| **`bounced`** | `Error` (`#D0021B`)의 밝은 톤 (예: `#FFEBEE`) | `Error` (`#D0021B`) | `❗` (Exclamation) |

---

### 2. `email_status` 수동 변경

뱃지 옆에 상태를 수동으로 변경할 수 있는 기능을 제공합니다.

- **컴포넌트:** 드롭다운 메뉴를 포함한 `변경` 버튼
- **버튼 스타일:** `Secondary Button`의 작은 버전 (padding: `4px 8px`)
- **상호작용:**
    1. `변경` 버튼 클릭 시 드롭다운 메뉴 표시
    2. 드롭다운 메뉴 상단에 경고 메시지 표시:
        - `"이 상태는 SendGrid 웹훅을 통해 자동으로 업데이트됩니다. 정말 수동으로 변경하시겠습니까?"`
    3. 메뉴 항목: `active`, `unsubscribed` 등 변경 가능한 상태 목록
    4. 상태 선택 후 `저장` 버튼 클릭 시 상태 업데이트
